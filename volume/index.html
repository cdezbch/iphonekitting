GC Set Volume 90

Sets the iPhone volume to 90% every time it is plugged in.

Add Shortcut

1. Add the shortcut

  1. Tap Add Shortcut above
  2. If Safari downloads it, open it from Downloads in Files
  3. Tap Add Shortcut in the Shortcuts app

2. Create the automation

  1. In Shortcuts, tap Automation, then +
  2. Choose Charger and select Is Connected
  3. Select Run Immediately and turn off Notify When Run
  4. Tap Next and pick GC Set Volume 90
