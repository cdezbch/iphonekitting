# BCH iPhone Kitting Instructions

Step-by-step kitting guide for CDW: labeling, SIM/eSIM, Setup Assistant, app permissions, device settings, quality check, and packing.

- **Web version:** https://cdezbch.github.io/iphonekitting/
- **PDF:** [BCH-iPhone-Kitting-Guide.pdf](BCH-iPhone-Kitting-Guide.pdf)

## Embedding in Confluence Cloud

Add an iframe macro (Aura's iFrame, or any HTML/iframe macro) with this URL:

```
https://cdezbch.github.io/iphonekitting/?embed=1
```

Suggested height: **1600px**, width **100%**. `?embed=1` (or simply being inside an iframe) strips the outer page margins and adds an "Open in a new tab" button.

Raw snippet, for macros that take HTML:

```html
<iframe src="https://cdezbch.github.io/iphonekitting/?embed=1"
        width="100%" height="1600" style="border:0" loading="lazy"
        title="BCH iPhone Kitting Instructions"></iframe>
```

This repo is public. Never commit Wi-Fi passwords, device passcodes, ship-to addresses, or serial/phone-number lists here — BCH sends those to CDW separately.

To update: edit `index.html`, then regenerate the PDF by opening the page in Chrome or Edge → Print → Save as PDF (Letter, no headers/footers).
